# MCP 配置

`servers.example.json` 是通用结构示例，不是已启用的客户端配置。当前没有配置任何服务器；按所用客户端文档确认支持的配置位置和字段后再接入。复制成 `servers.local.json` 仅用于本地维护，不会自动被客户端加载。

MCP 用于给开发代理提供工具；应用运行时模型和抖音访问由 `packages/adapters` 负责，二者不要混淆。优先接入有明确用途的只读文档或本地诊断工具，再评估外部写入能力。令牌通过客户端支持的安全环境配置传入，不写进 JSON；示例不得包含真实账号资料。

未来如开发项目自己的 MCP server，应作为独立 TypeScript workspace 包，并复用应用执行策略；不得绕过视频确认、低风险评论限制和预算门控。新增 server 前核验来源、工具清单和所需权限。
