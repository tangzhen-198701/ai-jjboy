# AI Douyin

基于 pnpm monorepo 与 TypeScript 的 AI 角色账号项目。当前实现人格编辑、本地模拟聊天和手动记忆管理，尚未接入真实模型、视频生成和平台操作。

## 启动

要求 Node.js 20.19+、pnpm 11。首次安装后提交 `pnpm-lock.yaml`。

```bash
pnpm install
pnpm check
pnpm dev
```

管理台默认 http://127.0.0.1:5173，后端健康检查 http://127.0.0.1:3100/health。worker 当前只输出状态后退出，没有后台消费循环。也可使用 `pnpm --filter @ai-douyin/admin dev` 单独启动。

## 本地人格与记忆原型

启动后可修改人格名称、背景和表达方式，每次保存增加版本号。聊天记录关联当时版本；目前只保留最新人格配置，尚无历史版本回滚。

回复为固定规则模拟：可试“今天失败了”或“你记得什么”。完整人格文本已传入适配器，但模拟器不会理解所有指令，关键词判断也不构成内容审核。

记忆只由用户主动添加，不自动从对话提取；支持删除。删除记忆不会删除包含该内容的历史聊天，需要时另行清空对话。聊天保留最近 100 条，记忆最多 200 条，模拟上下文使用最近 20 条记忆和 12 条消息。

数据写入 `data/workspace.json`（已忽略版本控制）。当前采用单服务进程内串行更新、临时文件原子替换；不支持多个后端进程同时写同一文件，后续迁移 SQLite。可通过 `WORKSPACE_DATA_PATH` 指定绝对数据文件路径。本地数据是明文，请勿添加密钥或敏感个人信息。

前端通过 Vite 代理访问 `/api`，默认后端端口 3100；修改 `PORT` 时需同步修改 `apps/admin/vite.config.ts` 代理。仅绑定本机，尚无用户身份认证，不可直接暴露到公网。`.env.example` 为变量示例，当前不会自动加载 `.env`，可通过启动进程的环境变量传入。

集成测试使用临时数据，覆盖人格更新、无效输入、并发聊天、重新打开数据后的恢复、记忆删除和跨站请求拒绝。浏览器验证已覆盖添加记忆、聊天引用和刷新恢复。演示数据均明确标记为演示，不代表真实用户偏好。
