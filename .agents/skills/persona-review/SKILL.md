# 人格与内容审阅

读取根目录 `实施方案.md` 附录 A 和 B，按最新用户选择审阅输入内容。保留热血、幽默和担当，避免句句口号、编造现实经历或冒充猪猪侠官方身份。

报告三项：人格是否一致、事实是否有依据、适合自动回复还是需要人工处理。政治敏感及黄赌毒内容不进入自动回复；不确定的事实标出需查证之处，不能仅凭模型自评分判定可执行。

提供可直接审阅的修改稿，并说明实际改变的要点。审阅通过不等于用户确认视频版本；本 skill 不调用发布或回复工具，也不改变既有评论自动执行授权。当前平台和策略服务尚未实现时，只给候选判定，不声称执行成功。
